# 最近新增功能摘要

更新时间：2026-05-15 00:00 +08:00

## 0.9.5

- 新增基于重定向的 SSRF 防护，默认阻止 3xx 跳转。
- 新增 `IFRAME_CSP`，可为 srcdoc iframe 配置 CSP。
- 新增用户侧 Markdown 渲染开关，可分别控制用户消息和助手回复。
- 新增 `TERMINAL_PROXY_HEADERS`，可为终端代理响应注入自定义头。
- Channel 现在支持流式响应，并可走完整聊天能力链路，包括工具、RAG、函数调用等。

## 0.9.3

- Voice Mode 新增静音控制、相机记忆、提示词开关等能力。
- 聊天页新增删除当前会话、回到顶部、助手内容编辑与续写等操作。
- 日历新增创建流程、提醒配置和更细的调度参数。
- 模型编辑页新增统一卸载控制。
- 新增 `USER_GROUPS` 模板变量和动态请求头变量。
- 新增公开聊天分享权限控制、MCP OAuth 服务端 URL 配置、LaTeX 复制快捷操作。

## 0.9.2

- 新增 PaddleOCR-vl 文档抽取支持。
- 新增 Firecrawl v2 Web 加载支持。
- 日历事件提醒可自定义分钟数。
- 新增自定义 API Key 请求头配置。
- 用户可断开指定 OAuth 会话。
- 新增来源数量超限提示、模型列表性能优化、启动页预加载优化等体验改进。

## 0.9.0

- 发布官方桌面应用。
- 新增定时自动化任务与聊天内自动化工具。
- 新增任务管理工具，可在聊天中拆分和跟踪任务。
- 新增完整日历工作区和事件管理。
- Azure OpenAI、Ollama Responses API、Mistral TTS 等能力补齐。
- 聊天输入支持重新附加已上传文件。
- 后台与模型相关的管理能力持续增强，例如模型删除、STT 控制、自动化限额等。

## 适合优先记住的方向

- 安全：SSRF 防护、iframe CSP、URL 校验、图片与文件访问控制。
- 工作流：自动化、任务、日历、Channel 流式对话。
- 管理：模型卸载、公开分享权限、OAuth/MCP 配置、终端代理头。
- 体验：Markdown 控制、LaTeX 复制、会话操作、Voice Mode 改进。
